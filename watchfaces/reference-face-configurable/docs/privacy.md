# 隐私说明 / Privacy notice

应用：耐力仪表·可配 / Endurance Dial Configurable  
适用版本：1.1.0  
更新日期：2026-10-26

## 中文

本表盘在设备上通过Garmin官方API读取时间、电量、步数、心率与心率区间、身体电量、恢复时间、最大摄氧量、出生年/性别、已保存跑步、系统周跑量、日出和系统天气，用于显示及本地计算；可用范围取决于设备。出生年和性别用于摄氧量等级计算。

应用设置保存在设备应用属性中，读取的数据在运行时缓存。表盘没有开发者运营的服务器、网络上传、广告、分析SDK或付款功能；开发者不会通过表盘接收上述数据，也不要求另建账户。

Garmin系统数据同步仍由Garmin及用户设置管理。卸载表盘不会删除Garmin的原始健康或活动记录。

若主动通过GitHub提交反馈，该内容由GitHub处理，公开issue会公开展示。请勿附健康记录、密码或其他敏感信息。

隐私问题和支持联系：[GitHub Issues](https://github.com/Zixiaobowen/garmin-face-it/issues)。请先描述问题，不要公开提交个人健康数据。反馈按维护者可用时间处理，不承诺固定响应时限。

## English

The watch face reads time, battery, steps, heart rate and zones, Body Battery, recovery time, VO2 max, birth year/sex, saved runs, system weekly running distance, sunrise and system weather through Garmin APIs on the device for display and local calculations, where available. Birth year and sex are used for VO2 max ratings.

Settings are stored in device application properties; read data is cached during execution. The watch face has no developer-operated server, network upload, ads, analytics SDK or payment functionality. The developer does not receive these data through the watch face, and no separate account is required.

Garmin system synchronization remains governed by Garmin and user settings. Uninstalling the face does not delete Garmin's original health or activity records.

If you voluntarily submit feedback through GitHub, GitHub processes that content and public issues are visible publicly. Do not include health information, passwords or other sensitive information.

For privacy questions and support, use [GitHub Issues](https://github.com/Zixiaobowen/garmin-face-it/issues). Describe the issue without posting personal health data. Responses depend on maintainer availability; no fixed response time is promised.
