工具异常与证据范围

6S Pro 首次并发模拟器编译遇到 SDK 内部错误，同一份源码单独编译成功，根因未确定。首次运行进程未找到 Java，后续显式指定已安装的 Java 17。一次 6X 启动进程在排查隐藏窗口时被停止，最终重启验收退出 0。

后段 macOS 截图接口返回“could not create image”。因此 6、6S 的证据限于正确机型已加载、构建与运行退出 0；画面验收以 6S Pro、6 Pro、6X Pro 的截图为准。原始失败和最终结果均保留在验证报告中。
