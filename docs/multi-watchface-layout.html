SDK、Java、官方设备包及仓库外签名密钥可以共用。每款新表盘使用独立 UUID；同一表盘更新继续沿用原 UUID。开发技能仍位于仓库根目录，通过技能路由选择具体表盘。

继续开发与新增表盘

在仓库根目录构建现有表盘：

python3 watchfaces/reference-face-configurable/scripts/build.py --device enduro3

也可以进入该表盘目录，继续使用原来的 python3 scripts/build.py。SDK、Java 与密钥准备见表盘说明；所有输出仍写在该表盘目录内。

  1. 使用官方 Monkey C: New Project，在 watchfaces/ 下创建新的 Watch Face 工程，并选择自己的最低 API 与设备目标。
  2. 保留新工程的独立 UUID、名称与入口。复用本表盘脚本时，调整 configure.py 的应用身份、权限和设备矩阵，以及 build.py 的产物前缀与默认目标。
  3. 在工作区 README及技能路由登记，并为新表盘记录构建命令与验证证据。
